# FAQ RAG Chatbot

A Retrieval-Augmented Generation chatbot that answers questions from your
company's FAQ PDFs and CSV, built entirely with free tools:

- **Embeddings**: HuggingFace `all-MiniLM-L6-v2` (runs locally, no cost)
- **Vector DB**: FAISS (local, free)
- **LLM**: Groq free-tier API (Llama 3.3 70B) — fast and free, just needs a free API key
- **UI**: Streamlit

The core RAG logic (`rag_engine.py`) is kept separate from the Streamlit UI
so it can be reused later, e.g. wrapped in a FastAPI endpoint for the
company website.

## Setup

1. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

2. **Get a free Groq API key**
   - Sign up at https://console.groq.com (free)
   - Create an API key
   - Copy `.env.example` to `.env` and paste your key in:
     ```
     cp .env.example .env
     ```

3. **Add your FAQ documents**
   - Put your PDF files and your CSV file into the `data/` folder
   - If your CSV has columns named `question` and `answer` (any case),
     it will be used directly. Otherwise every column is included as context.

4. **Build the vector index** (run this once, and again whenever your docs change)
   ```bash
   python ingest.py
   ```

5. **Run the chatbot**
   ```bash
   streamlit run app.py
   ```

## Project structure

```
faq_rag_chatbot/
├── data/              # put your PDFs + CSV here
├── faiss_index/       # generated by ingest.py, not checked in
├── ingest.py          # loads docs, builds the FAISS index
├── rag_engine.py       # reusable RAG query logic (no UI dependency)
├── app.py             # Streamlit chat interface
├── requirements.txt
└── .env.example
```

## Notes for going to production / website integration

- `rag_engine.py` has zero Streamlit dependency — you can import
  `RAGEngine` directly into a FastAPI/Flask app later and expose a
  `/chat` endpoint with no changes to the RAG logic itself.
- The Groq free tier has rate limits — fine for internal testing/demo,
  but check current limits at https://console.groq.com before scaling to
  real website traffic. Swapping to a paid Groq tier or another provider
  is a one-line change in `rag_engine.py` (the `ChatGroq(...)` line).
- Consider adding authentication and rate-limiting before exposing this
  publicly on the company website.
